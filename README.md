# Star Fighter

This is a Gorf-inspired space game I wrote for the Atari 2600 using Batari Basic.  You can play this on emulators or real hardware by running the latest .bin file in bin/.  The latest, and probably last, version is 1.06.

# Gameplay

Use the joystick to move the ship left and right.  The fire button fires the cannons.  Destroy the enemy ships and other hazards to get to the mothership on level 5.  Defeat it and you've saved the Universe!
